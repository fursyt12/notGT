### What's new in 0.15.9

- **A code title shows the selected row of a list from its first frame.** A code title
  that reads a list, such as `vars('guests.name')` in its script or `{{guests.name}}` in
  its HTML, was handed the whole list when it went on air instead of the row selected in
  Control → Data. The script found no `name` on a list and showed its fallback, and
  `{{…}}` always took the first row. The selected guest appeared only if some variable
  changed after the title had loaded, so on an out the title showed the right name only
  some of the time. A title that reads a single record, like `speaker`, was not affected.
  Now a code title starts with the selected row, as a title made from a file already did,
  and a change made while it is still loading reaches it as soon as it has loaded. The
  Editor's previews of a code title show the selected row too.
- **A list's column is deleted from its head.** Each column of a list in Control → Data
  now has a **×** beside its name in the list's head, shown on hover. It takes the column
  out of every row. A column that holds values asks first, and an empty one goes at once.
  With the last column gone, the rows are plain empty values again, as in a list made
  with “Turn into a list”. A list of more than six fields is shown field by field, with
  no head, so it has the same under **⋯ → Delete column**. In a list that mirrors an
  Excel sheet, the column is emptied in the workbook too.
