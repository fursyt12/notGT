### What's new in 0.15.3

- **Code animations take the size of their out.** **New animation → From code** made
  every code animation 1920×1080, whatever out it was made on, so on a 674×1180 out the
  animation was laid out at Full HD and shrunk into it. It now takes the out's size, as
  an animation from layers already did. An animation made before keeps its size: set
  **Width** and **Height** under **Animation** in the editor.
- **A debug checkbox in the Windows launcher.** The **Server log** window has a checkbox
  at its top: **Detailed NDI and Spout sender log**. Switched on, the sender writes into
  that log, every two seconds and for each out, how many frames it sends and how long
  they take. The launcher remembers the choice.
