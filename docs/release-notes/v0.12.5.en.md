### What's new in 0.12.5

- **Installing ffmpeg no longer crashes the launcher.** In 0.12.4, pressing
  “Install ffmpeg” in a launcher that was not started as administrator ended
  its service process after a few seconds (“the launcher's service process
  has ended”). Now the launcher checks its rights when the install starts
  and, if it has none, asks Windows for them (the UAC prompt). The download
  and the progress in the window work as before. If the prompt is refused,
  the window says so and the button becomes “Try again”.
- **Sturdier install.** Unpacking no longer holds the launcher while the
  antivirus scans the new files, files the antivirus briefly keeps busy are
  retried, and every failure ends as a message in the window instead of a
  crash.
- **A trace when something goes wrong.** If the launcher's service process
  ever crashes, the reason is written to `launcher\launcher-crash.log`.
