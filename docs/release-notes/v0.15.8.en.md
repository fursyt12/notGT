### What's new in 0.15.8

- **A list gets columns from its head.** A list in Control → Data now has **`+ Column`**
  beside **`+ Row`**: name the column, and every row gets it, empty. It replaces the
  “Add a column” item of the list's `⋯` menu, which did nothing on a list made with
  “Turn into a list”, since such a list holds plain values rather than fields. Now the
  first column makes it a table, and the values already in it move into a column of
  their own, `value` unless you name it otherwise; the form says that a title which
  showed `{{list}}` reads `{{list.value}}` from then on. A list of empty values just
  gets the column. A name that is already a column, or has `.`, `[`, `]`, `{` or `}` in
  it, is refused. The form stays open for the next column, and Esc closes it.
- **The title-generation prompt keeps titles to transform and opacity.**
  [`GENERATE_TITLES.md`](https://github.com/fursyt12/notGT/blob/v0.15.8/GENERATE_TITLES.md)
  and its Russian twin now tell the model never to animate `clip-path`, `mask`,
  `mask-image` or `filter`. On the Spout and NDI outputs a title is drawn by Electron's
  offscreen renderer, and in tests such animations were intermittently dropped on the
  first show: a wipe of a card, a pill or a slogan did not play at all, while a browser
  showed the same title correctly. The prompt gives the replacements — a sliding child
  inside a static `overflow: hidden` wrapper for a wipe, `scaleX` for a growing bar, a
  separate layer for a shadow — and asks for `fill: 'backwards'` on every entrance and
  for font sizes set from JS in `vw` or `calc(var(…))`, never `px`.
