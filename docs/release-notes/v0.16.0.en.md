### What's new in 0.16.0

- **Render an animation to a video file with alpha.** **`Render`** in the Editor's toolbar
  turns the open animation into a video file with its transparency: its entrance, the time
  on screen you choose, then its exit, with the variables as they are now (the selected row
  of every list). Three formats:
  - **WebM · VP9**, for OBS, browsers and notGT's own video layers;
  - **MOV · ProRes 4444**, for Premiere, DaVinci Resolve, Final Cut and After Effects;
  - **MOV · DXV3**, for Resolume, with premultiplied alpha.

  Frame rate 25, 30, 50 or 60. The render is made on the server, frame by frame on a
  stopped clock, so it is drawn exactly as the out page draws it and a slow machine makes
  it slower, never choppier. Unsaved edits are saved first; the toolbar button shows the
  progress, also with the dialog closed, and **`Stop`** ends a render. The finished file is
  offered for download and kept on the server for a day.

  The server needs a Chromium, Chrome or Edge to draw the frames: the Docker image now has
  Chromium, Windows 10 and 11 have Edge, on a Mac install Chrome (`NOTGT_BROWSER` names
  another one). WebM and ProRes are encoded by ffmpeg. DXV3 is written by notGT itself,
  since ffmpeg's DXV encoder has no alpha, and its frames are stored uncompressed: about
  50 MB a second at 1080p25.
- **The Docker image is about 300 MB larger** with Chromium in it
  (`--build-arg INSTALL_CHROMIUM=false` leaves it out), and runs the server under `tini`,
  which clears away the processes a render's browser leaves behind. Rebuild it with
  `docker compose up --build -d`.
