### Что нового в 0.15.9

- **Код-титр показывает выбранную строку списка с первого кадра.** Код-титр, который
  читает список, например `vars('guests.name')` в скрипте или `{{guests.name}}` в HTML,
  при выходе в эфир получал весь список, а не строку, выбранную в Control → Данные. Скрипт
  не находил у списка поля `name` и показывал запасное значение, а `{{…}}` всегда брал
  первую строку. Выбранный гость появлялся, только если какая-нибудь переменная менялась
  уже после загрузки титра, поэтому на out'е титр показывал нужное имя лишь иногда. Титры,
  которые читают одну запись, как `speaker`, это не затрагивало. Теперь код-титр сразу
  получает выбранную строку, как уже получал титр из файла, а изменение, сделанное, пока
  титр загружается, доходит до него, как только он загрузился. Превью код-титра в
  редакторе тоже показывают выбранную строку.
- **Столбец списка удаляется из его шапки.** У каждого столбца списка в Control → Данные
  теперь есть **×** рядом с названием в шапке списка, он появляется при наведении. Он
  убирает столбец из всех строк. Столбец со значениями сначала спрашивает, пустой
  удаляется сразу. Когда удалён последний столбец, строки снова становятся простыми
  пустыми значениями, как в списке из «Сделать списком». Список больше чем из шести полей
  показывается по полям, без шапки, поэтому у него то же самое есть в **⋯ → Удалить
  столбец**. В списке, который зеркалит лист Excel, столбец очищается и в книге.
