### What's new in 0.12.4

- **ffmpeg with one button (Windows).** The launcher's window now has an
  “Install ffmpeg” button while there is no ffmpeg. One press downloads the
  newest LGPL build for Windows from
  [BtbN/FFmpeg-Builds](https://github.com/BtbN/FFmpeg-Builds) (about 75 MB),
  checks it against the release's checksum and unpacks it into `ffmpeg\`
  next to the launcher; the window shows the progress. A running server
  picks it up without a restart — `.mp4` and `.mov` uploads are converted,
  and “as long as the video” can measure a clip. If the download fails, the
  window says why and the button becomes “Try again”.
- **A video layer's box matches the clip.** A new video layer starts as a
  real 16:9 box on any title size (before, on a lower third it was a thin
  strip). Uploading a clip or picking one from the list fits the box to the
  clip's own resolution, so the editor and the out show it alike, without
  stretching or empty bands.
- **The clip length is measured once ffprobe appears.** A server that once
  found no ffprobe no longer remembers a clip as having “no length”.
