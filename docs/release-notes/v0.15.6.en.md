### What's new in 0.15.6

- **The show in one file.** Titles & Outs → **Project** saves every animation, out and
  variable as one `.ngt` file, together with the media files they use, uploaded videos
  included, and opens such a file in place of all of that — here, or on another server.
  Opening reads the whole file first and refuses a damaged one without changing anything.
  It takes everything off air, so nothing the file had switched on goes on air by itself.
  A media file that is already on the server is used as it is, and a different file
  under a name that is taken gets a new name. The lists a connected workbook mirrors
  keep the workbook's rows, so opening a project never writes into a workbook. Only an
  administrator has the menu. What is in the file, and the format itself:
  [Project files (.ngt)](https://github.com/fursyt12/notGT/blob/v0.15.6/bundles/notGT/README.md#project-files-ngt).

0.15.5 was not published, so its changes come with this release:

- **A receiver that connects during a title gets it as it is.** With nobody receiving,
  the NDI sender rested the out at one frame a second, and Chromium takes a new rate only
  at its next frame. So a receiver that connected in the middle of a title waited up to
  a second and a half, got the title from its first frame, and missed the rest of it.
  Now an out with a title on it is painted at its full rate whether anyone receives it or
  not, an out with none rests at ten frames a second, and a new receiver is noticed
  within 50 ms. It gets the title as it is at that moment within about 60 ms, and every
  frame after.
- **Chromium's textures are kept on Windows.** The Spout sender opened Chromium's picture
  anew for every frame; it now opens each of the few textures Chromium draws into once.
  The native NDI converter kept them by the frame's handle, which Windows gives out again
  once closed; it now knows them by what they are, so it neither imports every frame
  again nor takes one texture for another.
- **For measuring.** In the title test (`scripts\bench.mjs --real`), `--connect
  0,250,500,1000` connects a receiver that many ms into each show and checks what it
  gets. `NOTGT_NDI_IN_FLIGHT` sets how many textures the WebGL2 converter holds at once.
