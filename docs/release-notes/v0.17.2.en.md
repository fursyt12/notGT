### What's new in 0.17.2

- **Every artist, also when only a source without lyrics credits them.** notGT Lyrics
  Bridge took the full list of artists only from a source that had the song's lyrics. For
  "ева киллер — собакам тут не место" LRCLIB has the lyrics and credits one artist, while
  NetEase credits all three but has no lyrics, so the Karaoke title showed one name. Now
  every song the sources match counts, lyrics or not. A track the bridge remembered before
  is asked for once more in the background, keeping the variant chosen and the shift.
  Download the new `notgt-lyrics-bridge.exe` from this page.
