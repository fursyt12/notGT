### What's new in 0.15.7

- **A code animation takes the shape of its out in one click.** A code animation is
  drawn in a frame of its own size and scaled onto the out, so one made at 1920×1080 and
  placed on a 674×1180 out stays 16:9, whatever its code does: “Fit out width” only
  scales it, and Scale Bounds does not make the frame bigger. When the shapes differ,
  the Editor's Placement tab now says so and offers **“Make the animation 674×1180”**:
  the animation gets the out's size, and its placement covers the whole out (position
  0, scale 1, no crop or bounds). Only the size is saved; other unsaved edits stay
  unsaved.
