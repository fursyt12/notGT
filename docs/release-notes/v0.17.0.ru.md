### Что нового в 0.17.0

- **Караоке из Spotify.** `notGT Karaoke.exe`, новая программа в Windows-пакете рядом с
  лаунчером, следит за тем, что играет Spotify на этом компьютере, находит синхронизированный
  текст и отправляет в notGT строку, которую сейчас поют. Её показывает новый пример
  **«Караоке»** в библиотеке: строка заливается слева направо (по словам, если у текста есть
  пословный тайминг), под ней следующая, а в паузах точки отсчитывают время. В уже
  существующие библиотеки пример добавляется один раз.
  - В окне программы укажите адрес notGT и, если сервер спрашивает, WebSocket-ключ (вкладка
    «Команда»); программа может работать и на другом компьютере, не на сервере. Закрытое окно
    прячется в область уведомлений, в меню значка — те же кнопки и **«Выйти»**.
  - Текст берётся из LRCLIB и NetEase, а из Musixmatch — с токеном вашей учётной записи.
    Тайминги песни из всех источников хранятся как варианты: **«Предыдущий / Следующий»**
    переключают их, если показанный расходится с песней, **«Раньше / Позже»** сдвигают текст
    на 100 мс, и то и другое запоминается для трека.
  - Нужна Windows 10 1809 или новее. Подробнее —
    [karaoke/README.md](https://github.com/fursyt12/notGT/blob/v0.17.0/karaoke/README.md).
- **Рендер бесшовной петли.** **`Зациклить`** в окне рендера сохраняет один цикл того, что
  движется в эфире, — с момента, когда появление закончилось, и без ухода, — так что файл
  играет по кругу без скачка. При длине петли 0 она находится по собственным бесконечным
  анимациям и зацикленным видео анимации (до 60 с); анимация «туда-обратно» сохраняет
  направление. Если такой короткой длины, что подходит всем, нет, окно говорит, какая часть
  на стыке смещена и через сколько всё вернётся к началу.
- **Рендер на другой машине.** `npm run render` в `bundles/notGT` рендерит анимацию любого
  сервера notGT (0.16.0 или новее) браузером и ffmpeg той машины, где запущен, — для
  сервера, который не может рендерить сам. Он только читает с сервера, в эфир ничего не идёт.
  ```
  npm run render -- --server http://192.168.1.20:9090 --user admin --password admin --list
  npm run render -- --server … --title "Нижняя треть" --format dxv --hold 5
  npm run render -- --server … --title "Side" --format webm --loop
  ```
- **«Браузер завершился при запуске» в Windows.** Браузер, который при запуске передаёт
  работу новому процессу, теперь дожидаются, найденные браузеры пробуются по очереди, а если
  рендер так и не стартовал, сообщение называет браузер и заканчивается тем, что он записал
  в журнал.
