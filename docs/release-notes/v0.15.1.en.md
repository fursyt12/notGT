### What's new in 0.15.1

- **Spout is a library of its own.** Spout used to live inside the NDI sender. It now has
  its own folder, `spout/`, with its own Rust crate, addon and README. The NDI sender
  still draws the out pages and hands the frames of Spout outs to it. The Windows package
  now always carries `spout/`, so nothing changes in how you use it.
- **Timers in out pages run on the server's clock again.** Pages opened with an out's key
  (OBS links, and the outs the NDI and Spout senders draw) could not ask the server for
  the time. Their timers ran on that computer's own clock, and the server logged
  `"message" refused: this key only reads` every minute for each one. Those keys may now
  ask for the clock, and still nothing else.
- **Each out's process has its own Chromium profile.** With every out in a process of its
  own, the processes shared one profile and fought over its caches (`Unable to move the
  cache` in the log). Each one now keeps its own.
- **Spout keeps its active sender.** The sender now keeps Spout's "active sender" record
  open for as long as it runs. Receivers that open "the active sender" without a name
  could find that record gone.
- **Known issue:** on one machine, a second Spout out stopped the first one playing in
  Resolume. This release does not fix it yet; it is being looked into.
