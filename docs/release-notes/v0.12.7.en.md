### What's new in 0.12.7

- **Scale Bounds: resize the box, not the animation.** A new tool next to
  Crop in the editor. Its frame has a handle on every corner and edge, and
  pulling one moves only that edge of the area the animation is shown in —
  inwards, or outwards past the template's own box, so whatever the
  animation draws there comes into view. The animation itself does not
  stretch, move or scale; what falls outside the new box is hidden, in the
  editor and on air alike. Only the new box is drawn, not the old corners.
  The inspector shows its size with “Clear”, “Reset” goes back to the
  template box, and the API takes it as `bounds` on a placement. A code
  animation renders inside a frame of the template's size, so growing its
  box past the template adds empty space.
