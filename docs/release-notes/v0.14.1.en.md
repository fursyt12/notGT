### What's new in 0.14.1 (beta)

- **The NDI sender starts on Windows again.** In 0.14.0 it never started there: its
  Electron quit at once with code -1, and no out was sent. Electron on Windows refuses
  a command line in which a switch follows anything that looks like a URL, and 0.14.0
  added `--render auto` after the server's address. Every value now goes to Electron as
  `--name=value`, and a test checks the sender's command lines against Electron's rule.
- **When the sender cannot start, it says why.** With `NOTGT_NDI_DEBUG=1` Chromium's own
  messages are printed on Windows too, the command line Electron is started with is
  shown, and an exit with -1 is explained. The NDI diagnostics
  (**NDI test - native converter.cmd**) keep everything the sender and Electron said,
  so a sender that does not start still leaves something to read in the zip.
